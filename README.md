# 《一朝天子》（网页游戏 Prototype）

以王朝为包装的轻量随机抽牌策略网页游戏原型。

> **核心验证目的**：验证「随机抽牌 → 阅读当前王朝局势 → 从不完美手牌中做取舍 → 打出一张牌 → 看到局势和王朝发生变化 → 想继续下一轮」的核心循环。

---

## 一、核心玩法与规则

1. **基本时间与局长**：
   - 目标长度 30～40 季（4 季 = 1 年，完整一局约经历 7～10 年）。
   - 生存至 40 季判定【江山暂安】。
2. **公开核心国家状态**：
   - **国库**：充盈 / 尚可 / 吃紧 / 枯竭
   - **民心**：归附 / 安定 / 不满 / 沸腾
   - **军势**：强盛 / 可战 / 疲弱 / 危殆
   - **朝局**：稳固 / 尚稳 / 暗流 / 失控
3. **天下局势机制**：
   - 场上最多同时存在 **3 个主要局势**，超出时严格执行合并或替换，绝非红点刷屏。
   - 局势不是“必须打某张对应卡才能解决”的死板任务，而是改变当前牌的价值与未来风险。
4. **手牌与保留机制**：
   - 抽 5 张奏折手牌（保证不全为同类牌，并根据历史倾向与国家状态动态微调权重）。
   - 每季正常打出 1 张牌。
   - 打牌后可挑选至多 1 张牌「留待下朝」，次季只补抽至 5 张。
5. **胜负条件**：
   - 失败：任意两个核心属性同时 ≤ 0，或某个重大危机恶化至最高失控等级（【王朝倾覆】）。
   - 胜利：成功治世生存满 40 季（【江山暂安】）。

## 二、项目结构

```
.
├── index.html                 # 游戏主页面 (16:9 御案奏折布局)
├── style.css                  # 静雅古朴御案水墨样式
├── server.js                  # 零依赖本地轻量静态服务器
├── package.json               # ES 模块规范配置
├── src/
│   ├── game.js                # 核心状态机与游戏流程控制
│   ├── data/
│   │   ├── balance.js         # 平衡数值与常量
│   │   ├── cards.js           # 27 张卡牌完整数据定义
│   │   ├── situations.js      # 16 种天下局势定义
│   │   └── states.js          # 10 种长期王朝状态定义
│   ├── engine/
│   │   ├── prng.js            # Mulberry32 可复现伪随机数生成器
│   │   ├── cardManager.js     # 牌库权重计算、手牌抽取与打牌逻辑
│   │   ├── situationManager.js# 局势生成、推进、合并与升级
│   │   ├── stateManager.js    # 四项属性限制与长期状态管理
│   │   ├── historyManager.js  # 史册编年史记录
│   │   ├── telemetry.js       # 遥测数据记录与 JSON 导出
│   │   └── saveManager.js     # LocalStorage 自动存档/读档
│   └── ui/
│       ├── renderer.js        # 界面主渲染器与盖印动效
│       ├── debugPanel.js      # Debug 监控与干预控制台
│       └── modal.js           # 终局弹窗与史册抽屉
└── test/
    ├── simulate.js            # 核心自动化验证脚本 (74项断言)
    └── batch_test.js          # 20 局无干预策略压力测试
```

---

## 三、快速开始

### 方式 1：使用内置 Node 服务器
```bash
node server.js
```
启动后在浏览器访问：`http://localhost:3000`

### 方式 2：使用任何静态 HTTP 服务
```bash
npx serve .
# 或
python -m http.server 3000
```

### 运行自动化测试
```bash
node test/simulate.js
node test/batch_test.js
```

## 四、Debug 与数据导出

- 点击右上角 **【DEBUG】** 面板可实时查看：四维精确数值、局势等级、动态牌池权重、历史行为倾向、随机种子。
- 支持一键 **【导出本局 JSON】** 与 **【复制数据到剪贴板】**，便于外部 AI 深度分析平衡性。
- 支持指定种子开局、调整属性、强制抽牌、强制生成局势以及无失败模式。
