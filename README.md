# 《一朝天子》（网页游戏 Prototype 0.3）

以王朝为包装的轻量王朝人生模拟 + 随机御前决策网页游戏原型。

> **0.3 核心设计定义**：彻底摆脱 0.1 的“四维数值增减按钮”和 0.2 的“看题找答案/灭火做题机”，转向**「自主运转的鲜活王朝生态 + 偶有决断的皇帝人生体验」**。
> 天下不是靠玩家推着走的，即使皇帝完全无为而治（纯旁观），人物也在经历生老病死、恩怨情仇，剧情线也在自然滋长；玩家的每一次【朱批】，都在数季乃至数十年后埋下因果回响（CausalHook），并可随时溯源「何以至此？」。

---

## 一、0.3 核心玩法与系统机制

1. **王朝自主演化生态（World Autonomous Simulation）**：
   - **动态人物群像**：6~10 位活跃在朝堂、边疆与内廷的关键臣僚。每个人物具备独立生卒年、性格特质（如刚直、圆滑、野心、尚武）、派系倾向、彼此私交/仇怨，以及个人专属人生记忆（3~6条近期生平）。人物会自主升迁、立功、弹劾、密谋、患病或老死。
   - **8条多阶段长线剧情 (Story Threads)**：涵盖【北境易主】、【边将韩策崛起】、【沈恪均田清赋】、【海舶与顾氏金山】、【东宫储嗣经略】、【台阁清浊党争】、【淮黄大水与循吏治平】、【西苑长生与广厦之思】。每个故事线跨越数季至数十年，自主推进或因玩家干预分叉。
   - **四方边塞漂移 (Regional Drift)**：北境、江南、中原、西陲四方疆土每季根据民生、治安、军势自主发生局势波动与流转。
   - **宫闱人生周期 (Imperial Lifecycle)**：后宫怀胎诞嗣、皇子公主起名、6岁入学启蒙、选配帝师（影响性格特质）、储君大婚分封，以及皇帝自身体力（康健/小恙/体弱/病重）与生老病死。

2. **极简御前决策（Emperor's Quarterly Decrees）**：
   - 每季皇帝至多做一次选择（零或单一决断）：
     - **【朱批奏折】**：从内阁呈递的至多 5 份奏折中准奏一份，盖上朱砂御印；
     - **【退朝 · 无为】**：本季不予批复，百官自裁，天下自转；
     - **【留中待议】**：将某份重大奏折扣留御案，留待下季再定（最多暂留1份）。
   - 奏折具备明确可预期的后果与未来因果线索，拒绝盲盒，也没有做题式最优解。

3. **长线因果回响与「何以至此？」溯源 (CausalHook & Traceback)**：
   - 皇帝的朱批不会立刻以干瘪数值呈现，而是埋下 2~20 季的延时因果钩子（CausalHook）。
   - 任何由皇帝朱批触发的后遗事件、人物提拔反噬或恩泽，均打上【朱批因果】印记。
   - 点击人物卡或实录中的**「何以至此？」**，即可展开从当年御案朱批到今日局面的完整因果链条条目。

4. **大行皇帝本纪与世代传承 (Succession & Annals)**：
   - 皇帝寿数已尽或病笃龙驭上宾时，触发《大行皇帝本纪》：自动为一生功过加盖庙号（太宗/世宗/高宗/哀帝等）与史册定评。
   - 拥有合格继承人时，支持**【继承大统 · 继续王朝】**：新帝登基，原朝臣、未尽剧情线、各方疆土与仇怨因果完整保留，王朝绵延不绝。

5. **御案水墨视效与沉浸式实录**：
   - PC 端 16:9 御案奏折视效，随春夏秋冬展现四时雅致色调与宫灯光晕。
   - 真实朱砂印章盖印下落动画与音韵。
   - 《实录》按天下大事、朝堂纷争、宫闱私闻分类汇编，可随时调阅。

## 二、六大标准调试场景（DEBUG 面板一键载入）

| 预设编号 | 场景名称 | 验证重点 |
| :--- | :--- | :--- |
| **Test A** | **纯旁观 (20季)** | 完全无玩家干预（全自动退朝），验证世界是否依然活跃、人物是否自然老去并发生恩怨、故事线是否自主演进，拒绝冷场。 |
| **Test B** | **提拔名臣沈恪** | 朱批重用沈恪，验证数季后沈恪均田清赋长线剧情被激活、保守派豪族反弹、并在人物生平中留下完整因果链。 |
| **Test C** | **养大将韩策** | 批准韩策节度北境，验证韩策边防声望暴涨、拥兵自重、在未来 8~16 季可能产生军阀割据风险与因果溯源。 |
| **Test D** | **完全昏君治世** | 崇道建醮、大兴土木、广选秀女、放任党争，验证朝局腐朽、国库枯竭与忠良离心，但不立即 Game Over，呈现盛极而衰的王朝挽歌。 |
| **Test E** | **储君15年成长** | 预置太子，加速跨越 60 季，验证启蒙、选配帝师、特质养成、大婚、参政等皇嗣完整生命周期。 |
| **Test F** | **皇帝驾崩与继位** | 皇帝直接进入病重临终，验证《大行皇帝本纪》庙号定评，以及新皇登基后天下朝臣、人际关系与因果链的无缝继承。 |

## 四、快速启动与验证命令

### 1. 本地启动游戏
```bash
node server.js
```
启动后在浏览器打开：`http://localhost:3000`

### 2. 运行自动化全量测试
```bash
node test/simulate.js
```
验证项目包括：
- 20 季纯旁观模式人物自主行为、生卒年与剧情推进验证
- 100 季（25年）连续自动化模拟与无崩溃验证
- 6 大预设测试场景 (Test A ~ Test F) 逐项断言
- 存档保存与重载完整性

### 3. 运行多局批量统计
```bash
node test/batch_test.js
```
统计指标输出：
- 故事连续率 (Story Continuity Rate)：保持在 30%~35%
- 人物复现率 (Character Recurrence Rate)：保持在 40%~45%
- 孤立事件占比 (Isolated Event Ratio)：低于 2%
- 平均事件回响间隔 (Avg Return Interval)：约 3.8 季
